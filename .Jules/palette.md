## 2024-05-18 - Fix Keyboard Accessibility on Hover-Revealed Actions
**Learning:** Hover-revealed interactive elements (like delete buttons hidden with `opacity-0 group-hover:opacity-100`) completely bypass keyboard users when they receive focus, as the element remains visually hidden unless explicitly given a `focus-visible:opacity-100` class. Furthermore, the parent container needs `focus-within:opacity-100` if the layout relies on hovering the parent to reveal the child action, and `focus-within:ring-2` to clearly indicate focus within complex layouts (like task notes or photo gallery items).
**Action:** Always pair `group-hover:opacity-100` on interactive elements with `focus-visible:opacity-100` and consider `focus-within:opacity-100` or `focus-within:ring-2` on parent containers to ensure keyboard navigability.
