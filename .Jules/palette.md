## 2024-07-11 - Mobile Menu Accessibility Enhancements
**Learning:** Adding ARIA states (aria-expanded, aria-controls) and focus-visible outlines to custom built mobile menus is essential for keyboard and screen reader accessibility, compared to pre-built components like Sheet which handle some of this natively.
**Action:** Always add proper ARIA roles and labels to custom interactive elements, especially icon-only buttons, and ensure they have visible focus states for keyboard navigation.
